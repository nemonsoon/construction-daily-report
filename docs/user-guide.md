# 使い方の説明書

日報まとめを使う方に向けた説明書です。
パソコンやプログラムに詳しくなくても、上から読めば使えるように書いています。

日報まとめのページ: https://nemonsoon.github.io/construction-daily-report/

## はじめる前に

用意するものは、次の2つだけです。

- パソコンのブラウザ（最近の Chrome、Edge、Firefox と、Safari 17.4 以降）
- 工事日報の Excel のファイル（.xlsx）。まずは見本で試せるので、無くても始められます

登録やインストールは要りません。
選んだファイルは、そのパソコンのブラウザの中だけで処理し、どこにも送りません。

## 使い方

ページで「見本で試す」を押すと、3つの手順が上から順に並んでいます。
上から順に進めると、最後に日報と集計表の Excel が手に入ります。

```mermaid
flowchart LR
    A[工事日報の Excel] --> B[要確認.xlsx<br>直してほしいセルを黄色に塗り<br>指摘の列に理由を書く]
    B --> C[人が黄色いセルを直して保存]
    C -->|指摘が残っている| B
    C -->|指摘が残っていない| D[日報.xlsx<br>集計表.xlsx]
```

### 1. 見本の日報をダウンロードする

「見本をダウンロード」を押すと、**見本_工事日報.xlsx** がダウンロードされます。
書き忘れや食い違いを9か所入れた、練習用の日報です。
見本のファイルは架空のデータです。
今お使いの日報で試すときは、この手順は飛ばしてかまいません。

### 2. 書き忘れを確かめる

日報の Excel を、枠にドラッグするか「ファイルを選ぶ」から選んで読み込みます。
読み込むと **要確認.xlsx** がダウンロードされます。
直してほしいセルは黄色く塗られ、右端の「指摘」の列に理由が書かれています。
同じ理由は、ページの画面にも一覧で出ます。

書き忘れや食い違いが無ければ、そのまま手順3へ進めます。

### 3. 日報と集計表にまとめる

要確認.xlsx の黄色いセルを Excel で直して保存し、手順3の枠に読み込みます。
指摘が残っていなければ、**日報.xlsx** と **集計表.xlsx** がダウンロードされます。
指摘が残っていると、日報と集計表は作らず、残っている所を一覧で知らせます。

直した要確認.xlsx をすでに持っているときは、手順3から始められます。
手順3でも、手順2と同じ確かめ方をします。

## 読み込める日報の形

読み込めるのは、1行に1日と1現場と1作業員の分を書く表の形の Excel です。
見出しには、日付、現場名、作業員名、開始時刻、終了時刻の5列が必要です。
天候、休憩(分)、作業内容、安全、備考の列は、あれば読み、無ければ空として扱います。
列の順番は問わず、見出しの名前で列を探します。
「作業日」「工事名」「天気」「氏名」「作業者」「始業」「終業」「休憩時間」のような、よく使われる別の言い方の見出しも読みます。
見出しは、すべてのシートの上から10行目までを探すので、上に題名や会社名の行がある Excel や、2枚目のシートに日報がある Excel も読めます。

日付は「2026/9/1」「2026年9月1日」「令和8年9月1日」「R8.9.1」のような書き方（後ろに「（火）」のような曜日が付いていてもよい）と、Excel の日付のセルのどちらでも読みます。
時刻は「8:00」「８：００」「8時30分」「8:00:00」のような書き方と、Excel の時刻のセルのどちらでも読みます。
日をまたぐ夜の作業は、終了時刻を「翌6:00」か「30:00」のように書くと、翌日の6時に終わったものとして読みます。
書き間違いと見分けるため、翌日だと書いていない行は「終了が開始より前」として指摘します。

## 作られるもの

日報.xlsx は、現場ごとに1枚のシートで、日付の順に1日1ページずつ並び、印刷すると1日1枚になります。
各ページには、作成と確認の押印の欄、日付と曜日、天候、作業員ごとの開始と終了の時刻と休憩と作業時間と作業内容、人数と合計、安全、備考を書きます。

![日報.xlsx の1枚](images/daily-report.png)

集計表.xlsx は、月ごとに1枚のシートで、対象の日報の期間と作成日、現場別の延べ人数と作業時間、作業員別の出勤日数と作業時間を書きます。
合計の行は Excel の数式なので、表の数字を手で直しても合計がそろいます。

![集計表.xlsx](images/summary.png)

どちらも A4 縦で横幅が1ページに収まる印刷設定にしてあるので、Excel から PDF に書き出せます。
現場名と作業員名は、元の日報に最初に出てきた順に並べます。

## 見つける書き忘れや食い違い

見つけたものは、要確認.xlsx で直してほしいセルを黄色く塗り、右端の「指摘」の列に理由を書きます。

![要確認.xlsx。直してほしいセルが黄色く塗られ、右端の「指摘」の列に理由が書かれている](images/review.png)

空欄と読めない値として、日付、現場名、作業員名、開始時刻、終了時刻の空欄と、時刻を「8時ごろ」のように書いたセルを見つけます。

- 「現場名」が空欄です
- 「開始時刻」の値を読み取れません（例: 8:00）

時刻の間違いとして、終了が開始より前の行、休憩が作業時間より長い行、同じ作業員が同じ日に2つの現場で時間が重なっている行を見つけます。

- 終了時刻が開始時刻と同じか、それより前です（夜の作業なら「翌6:00」のように書いてください）
- 同じ日の9行目（山田邸 新築工事）と時間が重なっています

同じ日と同じ現場の食い違いとして、行ごとに天候が違う場合と、同じ作業員の行が2つあって時間が重なる場合（同じ行を2回書き写したときなど）を見つけます。
午前と夕方のように時間が分かれていれば、同じ作業員の行が2つあっても指摘しません。

- 同じ日・同じ現場で天候が食い違っています（晴、雨）
- 同じ日・同じ現場に、時間の重なる同じ作業員の行があります（2・7行目）

## 困ったとき

### ファイルがダウンロードされない、保存した場所が分からない

ブラウザがダウンロードを止めることがあります。
できあがったファイルは、手順の中にファイル名の札で並んでいるので、札の「ダウンロード」を押すと、もう一度ダウンロードできます。

### 「読み込めませんでした。Excel のファイル（.xlsx）か確かめてください。」と出る

.xlsx の形のファイルだけを読み込めます。
古い形の .xls や、CSV のファイルは読み込めません。
Excel でファイルを開き、「名前を付けて保存」で「Excel ブック（.xlsx）」を選んで保存し直してから読み込んでください。

### 「見出しが見つかりません」と出る

日付、現場名、作業員名、開始時刻、終了時刻の5つの見出しのうち、見つからなかったものが続けて書かれています。
見出しの行に、その見出しがあるかを確かめてください。
見出しの書き方の幅は「[読み込める日報の形](#読み込める日報の形)」にあります。

### 手順3で「まだ○か所が残っているため、日報と集計表は作りませんでした」と出る

直し残しがあると、日報と集計表は作りません。
一覧に出ている所を直して保存し、もう一度手順3で読み込んでください。

### 夜の作業の終了時刻が指摘される

翌日に終わった作業は、終了時刻を「翌6:00」か「30:00」のように書いてください。
翌日だと書いていないと、書き間違いと見分けられないため、「終了が開始より前」として指摘します。

### 同じ現場なのに、集計表で別々に数えられる

現場名と作業員名は、全角と半角の違いと空白の数の違いだけをそろえます。
「山田邸」と「山田邸 新築工事」のように言葉が違うものは、別の現場として数えます。
日報の中で同じ書き方にそろえてから読み込んでください。

### 読み込みに時間がかかる

列の全体に入力規則（ドロップダウンの選択肢など）が付いている Excel は、読み込みに数秒かかることがあります。

## 御社の様式に合わせるとき

- 御社の指定の様式（1日1枚の帳票形式の日報や、決まった形の集計表）に合わせて、読み取りと書き出しを作り替えられます。
- 売上の集計（単価の表との突き合わせ）と PDF の出力は、今の日報まとめでは外しています。
- 動かすたびに料金がかかる外部のサービスは使っていません。
